# Post-unblinding VM robustness control

The original frozen VM has a small main-set computational-time difference from
all-endpoints geometry, despite essentially equal or worse total queue work.
That difference could come from using fewer macro candidates rather than good
model spatial knowledge. This is a POST-UNBLINDING explanatory control, not
parameter tuning, a new selected algorithm, or an untouched primary hypothesis.

Repeat VM2, all-endpoints geometry2, geometric-consensus2 and abstaining-hybrid2
in the SAME randomized native block. All retain the same portfolio/collision/
anchor/search. The abstaining provider returns no extra targets while retaining
portfolio preprocessing. A shuffled-VM control applies a bijection of available
free candidate coordinates to the genuine model's decoded route portfolio,
fixing start/goal and preserving overlap, consensus votes and target count.
Three deterministic shuffle seeds are averaged within each query. No new calls.

This stronger control prevents crediting reduced target-list size to meaningful
LLM knowledge. It cannot modify the frozen primary or retrospectively be called
pre-registered. Report separately from the main25-method comparison.
