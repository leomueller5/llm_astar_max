# LLM-A*-WW: weighted waypoints

This directory contains the team's primary improvement and its notebook evaluation:

- `llm_astar_ww/llmastar/`: LLM-A*-WW implementation.
- `LLM_AStar_WW.ipynb`: cached-response evaluation, ablations, and figures.
- `results/` and `figures/`: results included in the team report.
- `dataset/` and `docs/`: shared upstream assets.

See the [repository README](../README.md) for installation, execution, and results,
and the [team report](../Team22_Report.pdf) for the method and evaluation.

The separate adaptive-alpha and hybrid-search research, tests, and additional
benchmarks are collected in [further_improvements](../further_improvements/README.md).
They use their own research package and do not replace this directory's WW implementation.
