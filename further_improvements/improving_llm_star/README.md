# Supplementary research workspace

This package contains the adaptive-alpha and later experimental LLM-A* variants,
with offline evaluation scripts, cached responses, historical results, and tests.
It is separate from the team's primary LLM-A*-WW package.

See the [research overview](../README.md) for setup, scientific scope, results,
links to the reports, and instructions for running historical commands.

- `llmastar/`: research package, including original-compatible planners.
- `experiments/`: instrumentation, benchmark drivers, research logs, and results.
- `tests/`: offline automated checks.
- `dataset/`, `docs/`: links to shared upstream assets.

The original project is [SilinMeng0510/llm-astar](https://github.com/SilinMeng0510/llm-astar),
provided under the included MIT license. The frozen original implementation remains
available through `../llm-astar/`.
